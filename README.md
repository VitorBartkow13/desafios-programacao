## Resumo dos Conceitos Praticados

Durante os desafios foram praticados conceitos básicos da linguagem C, como declaração de variáveis, entrada e saída de dados utilizando `scanf` e `printf`, operações aritméticas e utilização de diferentes tipos de dados.

Os exercícios também ajudaram a reforçar a importância da sintaxe correta e da formatação da saída de dados, pois a plataforma Beecrowd valida automaticamente o código e exige que o resultado siga exatamente o formato solicitado pelo problema.
